An entry for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty. The program writes a single-line office joke to `/output/entry.txt`: a work password that expires every 90 days turns out to be the only deadline the company has ever enforced — the one punctual thing in an office that misses everything else.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
